# Clustering of Scintillation Signals

Решение задачи кластеризации сигналов сцинтилляционного детектора на 3 класса: два основных физических класса и один аномальный/смешанный.

---

## Содержание ноутбука

1. **EDA** — анализ сигналов детектора
2. **Предобработка** — baseline-коррекция
3. **Feature Engineering** — построение признаков:
   - `total_integral`, `tail_integral`, `tail_to_total`
   - `peak_amplitude`, `t_peak`, `rise_time_10_90`
4. **Анализ признаков** — корреляции, PCA (~69% дисперсии)
5. **Кластеризация** — KMeans и GMM (k=3)
6. **Интерпретация** — маппинг кластеров в классы 0/1/2
7. **Выводы**
